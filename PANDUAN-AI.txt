PEMBARUAN: AI KINI BERNAMA "ASTA" (TOMBOL MELAYANG DI KANAN BAWAH)
===================================================================
- Tidak ada lagi menu "Tanya AI" di navigasi dan tidak ada bagian AI di beranda.
  ASTA muncul sebagai ikon maskot melayang di kanan bawah semua halaman.
- Di atas ikon ada gelembung chat yang berganti tiap 5 detik: "Tanya aku" > "Masih bingung?" > "Ngobrol yuk".
  Ubah tulisan/waktunya di ai.js: cari  MSGS  dan  SWAP_MS.
- Klik ikon (atau gelembungnya) untuk membuka jendela ASTA. Tutup dengan tombol X, klik area gelap, atau tombol Esc.
  Di ponsel jendela tampil layar penuh.
- Maskot tertanam di ai.css (tidak perlu file gambar terpisah). Ingin ganti gambar? Ganti nilai  --asta  di bagian atas blok ASTA pada ai.css.
- Bila di kanan bawah sudah ada tombol lain dan saling menumpuk, naikkan ASTA: di ai.css ubah  --asta-bottom:18px  (mis. 96px).
- File yang berubah: index.html, ai.js, ai.css (versi ?v=2). Pengaturan AI di bawah ini tetap sama.

FITUR BARU: TANYA AI + EDITOR ANGGOTA
=====================================

A. GANTI NAMA ANGGOTA (semudah edit kalender)
  1. Buka admin-anggota.html di browser (dari situs: alamatkamu/admin-anggota.html).
  2. Ketik langsung di kolom nama. Enter = tambah nama di bawahnya. Panah = pindah urutan. Silang = hapus.
     Mengganti banyak nama sekaligus: tombol "Tempel daftar" (satu nama per baris).
  3. Tekan "Unduh anggota.js", lalu unggah ke GitHub (Add file > Upload files > Commit). Nama file harus anggota.js.
  Halaman Kepengurusan, hitungan anggota, dan pilihan nama di form Pujian & Kritik ikut berubah otomatis.

B. TANYA AI (3 langkah, semuanya gratis)
  Tanpa langkah ini pun halaman Tanya AI sudah jalan dalam "Mode cari SOP" (menampilkan SOP paling cocok
  lengkap dengan tabel dan alur, tanpa AI). Langkah di bawah mengaktifkan jawaban AI penuh.

  1) Ambil kunci API gratis
     Buka aistudio.google.com > Get API key > Create API key. Salin kuncinya. Jangan dibagikan ke siapa pun.

  2) Pasang penghubung (Google Apps Script)
     a. Buka script.google.com > Proyek baru (BUKAN dari Sheet aspirasi; ini proyek terpisah).
     b. Hapus kode bawaan, tempel seluruh isi apps-script-ai.gs, simpan.
     c. Ikon gigi (Setelan project) > Properti skrip > Tambahkan properti skrip:
          API_KEY = (kunci dari langkah 1)
        Opsional: DAILY_LIMIT = 300 (batas pertanyaan per hari), MODEL = nama model bila ingin ganti.
        Ingin pakai Claude? Tambah PROVIDER = claude dan isi API_KEY dengan kunci dari console.anthropic.com.
     d. Di editor pilih fungsi "setup" > Jalankan > setujui izin (Lanjutan > Buka bila ada peringatan).
     e. Pilih fungsi "tes" > Jalankan. Di Log eksekusi harus muncul balasan JSON. Bila error, cek kunci/model.
     f. Terapkan > Deployment baru > Aplikasi web:  Jalankan sebagai: Saya, Yang memiliki akses: Siapa saja.
     g. Salin URL berakhiran /exec. Tes: buka di browser, harus tampil "ok":true dan "kunci":"terpasang".

  3) Tempel URL ke situs
     Buka ai-config.js (editor teks biasa/GitHub, jangan WPS/Word), tempel URL di antara tanda kutip lurus:
       window.AI_ENDPOINT = "https://script.google.com/macros/s/.../exec";
     Unggah ke GitHub. Muat ulang paksa situs (Ctrl+Shift+R).
     Di halaman Tanya AI, label di samping nama bagian berubah dari "Mode cari SOP" menjadi "AI aktif".

C. MEMASUKKAN ISI BUKU PANDUAN KE AI
  AI membaca SOP otomatis (sudah ada di sop-data.js). Untuk buku panduan (PDF), teksnya harus diekstrak sekali:
  1. Buka admin-panduan.html. Pilih PDF (boleh banyak sekaligus; nama file = kode, mis. psdm.pdf).
  2. Tunggu tanda hijau, tekan "Unduh panduan-data.js", unggah ke GitHub.
  3. Setiap panduan direvisi, ulangi untuk buku itu saja (editor memuat data lama, yang lain tidak hilang).
  Jawaban AI lalu menyebut "Panduan ... hlm. N" dan menautkan ke halaman PDF-nya.

KODE GALAT DI HALAMAN TANYA AI
  A0 endpoint kosong (mode cari)   N1 tidak bisa menghubungi skrip (akses bukan "Siapa saja"/URL salah)
  N2 jawaban bukan dari skrip      K1 API_KEY belum diisi      L1 batas harian tercapai
  E1 AI/penyedia error (cek Log eksekusi di Apps Script > Eksekusi; biasanya kunci salah atau model diganti nama)
  Pada semua galat, pengunjung tetap mendapat hasil pencarian SOP, bukan layar kosong.

CATATAN
- Kunci API hanya ada di Properti skrip, tidak pernah masuk ke GitHub atau browser pengunjung.
- Batas harian (DAILY_LIMIT) melindungi kuota gratis dari penyalahgunaan.
- Bila nama model Gemini diganti Google di kemudian hari, isi properti MODEL dengan nama terbaru di aistudio.google.com.
- Setiap SOP direvisi: ganti sop-data.js seperti biasa; AI otomatis memakai versi terbaru.
- Unggah SEMUA file baru: ai.js, ai.css, ai-config.js, anggota.js, panduan-data.js, index.html, admin-anggota.html, admin-panduan.html.
  Jangan menimpa aspirasi-config.js milikmu.
