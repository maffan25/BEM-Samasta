Editor Rapot Anggota

Pilih periode, isi nilai tiap anggota, lalu unduh rapot.js dan unggah ke GitHub. Nama anggota diambil otomatis dari anggota.js.

Ada draf yang belum diterbitkan dari sesi sebelumnya di perangkat ini.

Cara mengisi dan menerbitkan
  1. Pilih periode. Untuk periode baru, tekan Periode baru dan beri nama.
  2. Ketik nilai 0 sampai 100 pada tiap aspek. Rata-rata dan predikat (A sampai D) dihitung otomatis. Kolom kosong berarti belum dinilai. Anggota tanpa nilai dan catatan tidak tampil di situs.
  3. Untuk mempercepat, tekan Isi cepat di tiap unit, lalu ubah nilai yang berbeda saja.
  4. Selesai, tekan Unduh rapot.js. Di GitHub: Add file, Upload files, seret file itu (nama harus persis sama), lalu Commit changes.
Atur aspek penilaian

Tulis satu aspek per baris. Mengganti nama aspek membuat nilai lamanya tidak terbawa.
