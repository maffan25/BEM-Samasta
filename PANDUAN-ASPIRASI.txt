MENYAMBUNGKAN FORM PUJIAN & KRITIK KE GOOGLE SPREADSHEETS
=========================================================

File yang terlibat:
  aspirasi-config.js       TEMPAT MENEMPEL URL (satu-satunya file yang kamu isi)
  aspirasi.js              logika form di website (sudah jadi, tidak perlu diubah)
  apps-script-aspirasi.gs  kode yang ditempel di Google Sheets

LANGKAH
1. Buat Google Sheet baru (nama bebas, misal "Aspirasi BEM STDIIS").
2. Di Sheet itu: menu Ekstensi > Apps Script.
3. Hapus kode bawaan, lalu tempel seluruh isi apps-script-aspirasi.gs. Klik ikon simpan.
4. Ikon gigi (Setelan project) > Zona waktu: pilih (GMT+07:00) Jakarta.
5. Klik Terapkan > Deployment baru > ikon gigi > pilih "Aplikasi web", isi:
     Jalankan sebagai : Saya
     Yang memiliki akses : Siapa saja
   Klik Terapkan, lalu Izinkan akses. Bila muncul peringatan "Google belum memverifikasi
   aplikasi ini", pilih Lanjutan > Buka (aman, ini skrip milikmu sendiri).
6. Salin "URL aplikasi web" (berakhiran /exec).
7. Buka aspirasi-config.js, tempel URL di antara tanda kutip lurus ("):
     window.ASPIRASI_ENDPOINT = "https://script.google.com/macros/s/.../exec";
   Sunting dengan editor teks biasa atau editor GitHub, JANGAN dengan WPS/Word
   (bisa mengubah tanda kutip dan merusak file).
8. Unggah SEMUA file hasil zip ke GitHub (index.html, sop-app.js, aspirasi.js,
   aspirasi-config.js). Setelah itu buka website lalu muat ulang paksa
   (Ctrl+Shift+R, atau di HP: hapus cache browser) agar versi lama tidak terpakai.
9. Tes: kirim satu pesan dari website. Tab baru bernama "Aspirasi" akan dibuat otomatis,
   berisi kolom Waktu, Jenis, Bagian, Penerima, Pesan.

CATATAN PENTING
- "Siapa saja" hanya berlaku untuk URL penerima pesan. Spreadsheet-nya tetap privat
  dan hanya bisa dibuka akun yang kamu beri akses. Jangan bagikan link Sheet secara luas.
- Anonim: yang tersimpan hanya waktu, jenis, bagian, penerima, dan isi pesan.
  Tidak ada nama, email, akun, atau IP pengirim.
- Bila suatu hari kode .gs diubah: Terapkan > Kelola deployment > ikon pensil >
  Versi: Versi baru > Terapkan. URL tetap sama.
- Tes cepat endpoint: buka URL /exec di browser, harus muncul {"ok":true,...}.
- Jeda 20 detik antar kiriman dan batas 10 sampai 1000 karakter bisa diubah di bagian
  CONFIG pada aspirasi.js (dan MIN_LEN / MAX_LEN di file .gs).
- Daftar bagian dan nama di form dibaca otomatis dari bagian Kepengurusan di index.html,
  jadi bila ada nama yang diganti di sana, form ikut berubah.

JIKA PESAN TIDAK MASUK KE SHEET (cek berurutan)
1. Di editor Apps Script, pilih fungsi "setup" di bar atas, klik Jalankan, setujui izin.
   Tab "Aspirasi" harus muncul di Sheet. Kalau error "Tidak ada Spreadsheet", kode ditempel
   di tempat yang salah: buka Sheet dulu, baru Ekstensi > Apps Script (jangan dari script.google.com).
2. Terapkan > Deployment baru (atau Kelola deployment > pensil > Versi baru). Kode yang diubah TIDAK
   aktif sebelum dideploy ulang. Akses harus "Siapa saja" (bukan "Siapa saja dengan akun Google").
3. Buka URL /exec di browser (mode incognito). Harus tampil "ok":true dan "sheet":"terhubung".
4. Website versi ini membaca jawaban skrip, jadi bila gagal akan tampil kode:
   C0/C1/C2 : file aspirasi-config.js kosong/rusak/format URL salah.
   N1       : tidak bisa menghubungi skrip (akses bukan "Siapa saja", URL salah, atau offline).
   N2       : jawaban bukan dari skrip (biasanya halaman login Google, akses salah).
   S1/S2    : data form ditolak skrip. S3: skrip tidak terhubung ke Sheet. S4: gagal menulis.
5. PENTING saat mengunggah ke GitHub: aspirasi-config.js harus tetap berisi URL /exec milikmu.
   Jangan menimpanya dengan file kosong dari zip.
