Editor Isi Buku Panduan untuk AI

Agar AI bisa menjawab dari buku panduan, teks dari PDF perlu diekstrak sekali. Pilih PDF, unduh panduan-data.js, lalu unggah ke GitHub. Proses berjalan di perangkatmu, PDF tidak dikirim ke mana pun.

Nama file harus sama dengan kode buku, misalnya psdm.pdf. Cocok otomatis.
Cara menerbitkan
  1. Pilih PDF buku panduan (satu per satu atau banyak sekaligus). Tunggu sampai muncul tanda hijau dan jumlah halaman.
  2. Tekan Unduh panduan-data.js.
  3. Di GitHub: Add file, Upload files, seret panduan-data.js (nama harus sama), lalu Commit changes.
  4. PDF aslinya tetap diunggah ke folder panduan/ seperti biasa agar tombol Buka dan Unduh jalan.
  5. Bila PDF hasil scan (berupa gambar), tidak ada teks yang bisa dibaca. Ekspor ulang dari Word atau Google Docs sebagai PDF.
