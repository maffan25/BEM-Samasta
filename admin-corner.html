Tambah atau ubah corner, menu, event, dan aspek penilaian. Setelah selesai, unduh corner-data.js lalu unggah ke GitHub.

Ada draf yang belum diterbitkan dari sesi sebelumnya di perangkat ini.
Cara menerbitkan perubahan ke situs
  1. Selesai mengubah, tekan Unduh corner-data.js.
  2. Buka repositori situs di GitHub, tekan Add file, lalu Upload files.
  3. Seret file corner-data.js yang baru diunduh. Nama harus persis sama, sehingga file lama otomatis tertimpa.
  4. Tekan Commit changes, tunggu 1 sampai 2 menit, lalu muat ulang situs.
  5. Kode QR absensi baru hanya bisa dipindai setelah event itu terbit di situs.
