Pertanyaan penilaian

Dipakai semua event, kecuali event yang punya pertanyaan sendiri. Nama, NIM, dan bagian di BEM selalu ditanyakan lebih dulu, tidak perlu ditambahkan di sini.

Kata penutup

Ditampilkan setelah peserta selesai mengisi. Tulis {nama} untuk nama depan peserta, {event} untuk judul acara, dan {corner} untuk nama corner.

Pengaturan absensi

PIN untuk membuka corner

Hanya pengurus yang tahu PIN yang bisa membuka corner dari beranda. Peserta yang memindai barcode absensi tidak memerlukan PIN. PIN tidak disimpan sebagai teks, hanya sidik digitalnya (SHA-256 dengan garam) di corner-data.js.

Situs ini statis (tanpa server), jadi PIN menghalangi pengunjung biasa, bukan orang yang membongkar kode sumber. Jangan memakai PIN yang sama dengan PIN penting lain. Setelah mengubah, unduh corner-data.js dan unggah ke GitHub seperti biasa.

Cara menerbitkan perubahan ke situs
  1. Selesai mengubah, tekan Unduh corner-data.js.
  2. Buka repositori situs di GitHub, tekan Add file, lalu Upload files.
  3. Seret file corner-data.js yang baru diunduh. Nama harus persis sama agar file lama tertimpa.
  4. Tekan Commit changes, tunggu 1 sampai 2 menit, lalu muat ulang situs.
  5. Agar absensi tersimpan ke Google Sheets, isi corner-config.js dengan URL Apps Script (lihat PANDUAN-CORNER.txt).
